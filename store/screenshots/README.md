# Screenshot capture matrix

Screenshots must be captured from the actual internal-track release build; generated or composited UI images are not acceptable.

Capture the following four phone screens in `en-US`, `pt-PT`, `es-ES`, `fr-FR`, and `de-DE`:

1. Map with station price markers and no precise home/location visible.
2. Search and filtering results.
3. Station detail with price and driving-cost information.
4. Appearance selection showing the unlocked options.

Use a supported Play phone aspect ratio, hide status-bar notifications and personal data, and keep source screenshots unscaled. Place final PNG/JPEG files under `store/screenshots/<locale>/`.
